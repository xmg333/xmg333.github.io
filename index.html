// COLLECTION ENGINES
Components
01 / ENGINE
Spark Plugin
Transparent Spark metrics via SparkPlugin API and SparkListener. Captures task/stage IO, shuffle, JVM, and SQL query metrics. Supports Spark 2.4 / 3.x / 4.x.
SPARK OTLP gRPC Omnipackage
02 / ENGINE
MapReduce Telemetry
MR Collector polls History Server REST API. MR Agent uses ByteBuddy instrumentation for task-level metrics. Covers HDFS IO, shuffle, and job counters.
MAPREDUCE ByteBuddy REST API
03 / ENGINE
Hive Hook
ExecuteWithHookContext-based telemetry for HiveServer2. Captures query duration, IO bytes/rows, input/output tables. Compatible with Hive 2.x / 3.x.
HIVE Hook SQL Capture
04 / PIPELINE
Flink Consumer
Kafka → Flink → MySQL/ClickHouse streaming pipeline. 15-table wide-row schema with histogram bucket support and stage governance pre-aggregation.
FLINK 1.18 KAFKA JDBC Sink
